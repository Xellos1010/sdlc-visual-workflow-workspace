KEY DATA FLOWS
→ Skill invocation: Skill → gRPC → Rust service → PAL → Aurora. Result streamed back to skill + emitted as event to all workspace subscribers.
→ Web app update: Event lands in EventBridge → API GW WebSocket broadcasts to all connected team members → React UI updates live.
→ Approval decision: Human approves in web or skill → decision event emitted → confidence engine updates score → threshold check → auto-approve or queue next review.
→ Code generation: Spec + diagrams → IR pipeline → generation engine → target framework code → test runner → dependency-sorted failure tree → skill/web displays result.
