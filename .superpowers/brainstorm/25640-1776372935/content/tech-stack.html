Tech Stack

The stack determines how fast we ship and how the real-time collaboration and event sync work. One decision — everything else follows.

A

Next.js 14 + Supabase Recommended

Full-stack TypeScript throughout. Supabase handles auth (GitHub + email built-in), Postgres event store, Realtime WebSockets for collaboration, and file storage for artifacts — all in one platform. Skills are Node/TS, web app is Next.js, same language end to end.

SKILL LAYER
TypeScript · Node · existing skill pattern
WEB APP
Next.js 14 App Router · React · Tailwind · shadcn/ui
BACKEND / API
Next.js API routes · Supabase Postgres
REALTIME + AUTH
Supabase Realtime · GitHub OAuth built-in
✓ Auth + realtime + storage = zero config ✓ TS end to end ✓ Row-level security for workspaces ✓ Fastest to production
B

Next.js + Custom API + PostgreSQL

Next.js frontend with a separate Fastify/Express API server and self-hosted PostgreSQL. More control over every layer. Real-time via Socket.io. Auth via NextAuth. More setup, more flexibility.

API SERVER
Fastify · TypeScript · Socket.io
DATABASE
PostgreSQL · Prisma ORM · Redis pub/sub
✓ Full control ✓ Self-hostable ⚠ Significantly more setup ⚠ Auth and realtime from scratch
C

SvelteKit + Cloudflare (Edge-first)

SvelteKit on Cloudflare Pages + Workers + D1 (SQLite at edge) + Durable Objects for real-time. Globally distributed with near-zero latency. Smaller bundle, faster UI. Less TypeScript ecosystem overlap with existing skills.

FRONTEND
SvelteKit · Tailwind
BACKEND
Cloudflare Workers · D1 · Durable Objects
✓ Global edge performance ⚠ Different from existing TS skill ecosystem ⚠ Cloudflare platform lock-in
Why A wins for this system

The event-driven sync model maps perfectly to Supabase's Realtime — you emit an event row, all subscribers (web app + other skill sessions) receive it instantly. GitHub OAuth is a toggle, not a build. Row-level security enforces workspace isolation at the database level — zero application-layer auth logic needed. And the skill layer stays plain TypeScript, consistent with every existing skill in the repo.
