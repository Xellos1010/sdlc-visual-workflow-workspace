EVENT BACKBONE
UNIVERSAL EVENT SCHEMA
{
  id:           uuid,
  workspace_id: uuid,       // always scoped
  project_id:   uuid?,      // optional
  type:         EventType,  // see taxonomy
  actor_id:     uuid,       // user or agent
  actor_type:   'user' | 'agent',
  payload:      JSONB,      // type-specific
  timestamp:    timestamptz,
  conf_delta:   float?      // confidence impact
}

CONFIDENCE MODEL
Score = weighted rolling avg of ApprovalDecisions for a given gate_type in a workspace.
conf_delta on each event = how much this decision shifts the score.
When score ≥ threshold → approval.auto event fires — no human needed.
Human can override any auto-approval, which feeds back into delta.
Per workspace, per gate_type: score ∈ [0, 1] Default threshold: 0.85 Configurable per gate
DESIGN RULES
→ Every write to the DB emits a corresponding event — no silent mutations
→ Events are append-only — never deleted, full audit trail always available
→ All entities scoped to workspace_id — row-level security enforces isolation
→ content_url on artifacts points to S3 — DB holds metadata only, not file content
→ dep_tree on TestRun is a JSONB DAG — root-cause failures computed by Rust test-runner
