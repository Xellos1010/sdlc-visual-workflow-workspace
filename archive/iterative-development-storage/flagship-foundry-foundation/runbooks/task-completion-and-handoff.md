# Task Completion and Handoff Runbook

## Purpose
Ensure another human or agent can resume the work without hidden context.

## Inputs
- completed or partially completed work orders
- evidence bundles
- graph mutations
- continuity state

## Steps
1. Summarize what was attempted and what changed.
2. Link evidence to each acceptance claim.
3. Record blockers, open questions, and rollback notes.
4. Update continuity state and next work orders.
5. Create or update fix-memory when applicable.
6. Publish a handoff note in repo docs.

## Outputs
- continuity update
- artifact index
- next-step recommendations
- reusable learning references
