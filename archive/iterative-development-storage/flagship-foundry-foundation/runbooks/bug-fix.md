# Bug Fix Runbook

## Purpose
Contain, reproduce, fix, verify, and learn from a bug with minimal blast radius.

## Inputs
- bug or incident change request
- observed evidence
- affected contracts and guardrails

## Steps
1. Capture symptoms and environment.
2. Classify severity and user impact.
3. Reproduce or bound the issue with evidence.
4. Generate a minimal remediation plan.
5. Execute a bounded fix work order.
6. Run independent verification.
7. Write fix-memory and prevention rules.

## Outputs
- repro or bounded evidence
- remediation work orders
- verifier evidence bundle
- fix-memory record
