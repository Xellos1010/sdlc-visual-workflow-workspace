# Change Management Runbook

## Purpose
Coordinate deliberate changes that span multiple systems, contracts, repos, or release surfaces.

## Inputs
- change request
- system ownership map
- contract and deployment dependencies

## Steps
1. Confirm the change category and risk posture.
2. Enumerate impacted systems and owners.
3. Identify contract and rollout dependencies.
4. Define the review and approval chain.
5. Generate system-scoped work orders.
6. Define verification and rollback checkpoints.
7. Publish release and handoff artifacts.

## Outputs
- impact matrix
- approval path
- cross-system work-order plan
- rollout and rollback notes
