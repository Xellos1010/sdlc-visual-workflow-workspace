# Guardrail Pack Authoring Runbook

## Purpose
Create or refine a language, platform, or cloud guardrail pack.

## Inputs
- target scope
- known best practices
- common bug classes
- acceptance checks

## Steps
1. Define the scope and authority source.
2. Write mandatory rules and anti-patterns.
3. Define required checks and escalation conditions.
4. Attach known failure modes and examples.
5. Validate against existing runbooks and personas.
6. Publish and register the guardrail pack.

## Outputs
- guardrail pack
- catalog update
- linked runbook and persona references
