# Feature Intake Runbook

## Purpose
Turn an intended capability into typed work orders without skipping contracts, risks, or acceptance criteria.

## Inputs
- change request
- graph neighborhood
- relevant principle cards
- applicable guardrail packs

## Steps
1. Restate the requested outcome in one sentence.
2. Enumerate impacted systems and contracts.
3. Attach relevant principle cards and guardrail packs.
4. Define acceptance criteria and rollback posture.
5. Create ecosystem and system planning work orders.
6. Decompose repo and verifier work orders.
7. Publish the handoff envelope.

## Outputs
- approved change request
- work-order tree
- graph patch preview
- continuity update
