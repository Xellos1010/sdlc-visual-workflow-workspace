# Agent Marketplace Direction

## Long-term idea

The ecosystem should support a marketplace of:
- personas
- guardrail packs
- provider adapters
- terminal adapters
- domain principle packs
- execution recipes

## Marketplace contract

Marketplace items should always resolve to typed artifacts already supported by the core system:
- persona pack
- guardrail pack
- adapter manifest
- principle card bundle
- runbook bundle

## Safety rule

Marketplace assets must be reviewable, attributable, and versioned. No marketplace item should execute as opaque hidden logic.
