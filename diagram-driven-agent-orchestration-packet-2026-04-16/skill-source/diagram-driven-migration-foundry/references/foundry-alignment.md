# Foundry Alignment

Use this skill with a Foundry-style SDLC as follows:

- discover / define / visualize / architect before implementation fan-out
- chunk work into bounded work orders
- keep continuity state machine-readable
- use an analyzer gate before porting or migration
- require verifier evidence before release claims

If the workspace already has team-builder / team-launcher conventions, generate artifacts that fit those conventions rather than inventing a parallel structure.
