## Medium post (LinkedIn / dev.to intro)

**Announcing a public repo: SDLC Visual Workflow / Flagship Foundry**

Shipping software with AI assistants only scales if you treat the system as a **first-class graph**: what you import, what you know, what is missing, what you plan, and how you run and verify work — with clear continuity between sessions and tools.

This repository is now **public**. It is an **Nx monorepo** whose main runnable product is **Flagship Foundry** (`apps/flagship-foundry/`): a **control plane** HTTP API, an **orchestrator CLI**, schemas, runbooks, personas, guardrails, and a **Cursor / VS Code companion** surface. The goal is an SDLC loop that starts from an **existing workspace**, not a greenfield fantasy: import → knowledge → gaps → focus → plan → approve → run, with machine-readable continuity (see `.foundry/` and project docs).

**Why open it?** So others can reuse the patterns, harden the control plane, and align agent orchestration with real repo layouts — without hiding the rough edges.
