# Minimum Executable Slice

The minimum slice now proves nine things end to end:

1. import an existing ecosystem from a filesystem workspace or export bundle;
2. build a graph of systems, projects, frameworks, platforms, rules, diagrams, task states, and agent environments;
3. ingest foundational documentation into a versioned knowledge base;
4. analyze knowledge gaps against required domain packs;
5. generate Mermaid visualizations, focus views, and SME profiles;
6. create a plan with manual or auto approval policy;
7. insert debate and reconciliation tasks for risky plans;
8. create and control a run with start, pause, resume, and stop;
9. surface the same flow through a Cursor-compatible companion extension.

## Core commands

```bash
npm run bootstrap:full-sample
npm run api
npm test
```

## Sample assets

- `examples/current-workspace/input/` holds the imported workspace export bundle used for the demo.
- `examples/knowledge-sources/input/` holds the seed documentation sources and manifest.
- `state/ecosystems/web-automation-workspace/` holds the generated graph, report, visualizations, focus views, and SME profiles.
- `state/knowledge/foundry-foundational-docs/` holds the ingested knowledge base and coverage report.
