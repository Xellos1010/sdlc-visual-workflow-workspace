# Generic Doc Scraper Nx application for generic documentation extraction with browserless-first strategy and Playwright fallback. ## Run ```bash pnpm nx run generic-doc-scraper:scrape -- \ --input data/manifests/proof.json \ --input-format json \ --output-root docs \ --mode auto \ --concurrency 6 ``` ## Fastest Pattern (Large Sites) Use HTTP for full coverage, then retry only failures with browser fallback: ```bash pnpm nx run generic-doc-scraper:scrape -- \ --input data/manifests/coinbase-cdp-sitemap.csv \ --input-format csv \ --output-root docs \ --mode http \ --concurrency 20 \ --allow-partial ``` Generate a failed-only CSV from the latest run: ```bash node scripts/build-failed-csv-from-run.mjs --source-root docs/coinbase-cdp --output data/manifests/coinbase-cdp-failed.csv ``` Retry only those failed pages with auto/browser fallback: ```bash pnpm nx run generic-doc-scraper:scrape -- \ --input data/manifests/coinbase-cdp-failed.csv \ --input-format csv \ --output-root docs \ --mode auto \ --concurrency 6 ``` ## CLI - `--input <path>` required - `--input-format auto|csv|json` default `auto` - `--output-root <path>` default `docs` - `--source-id <id>` - `--mode auto|http|browser` default `auto` - `--concurrency <n>` default `6` - `--branch <name>` - `--include-page-types <csv>` - `--allow-partial` - `--verbose` ## CSV schema Header columns: `url,source_id,branch,page_type,category,group,slug,protocol,tags` `url` is required. ## JSON manifest schema ```json { "version": 1, "defaults": { "adapter": "readme", "branch": "2-Production", "includePageTypes": ["reference", "guide"] }, "sources": [ { "id": "proof", "baseUrl": "https://dev.proof.com", "adapter": "readme", "branch": "2-Production", "includePageTypes": ["reference", "guide"] } ] } ``` ## Cursor Learning Path Canonical input: [data/manifests/cursor-learn.csv](../../data/manifests/cursor-learn.csv) (requires `url` column). | Target | Description | |--------|-------------| | `scrape:cursor-learn` | Scrape all lessons from the canonical manifest | | `scrape:cursor-learn:discovered` | Scrape URLs from [cursor-learn-discovered.csv](../../data/manifests/cursor-learn-discovered.csv) (sitemap-generated) | | `concat:cursor-learn` | Write `cursor-learning-path-combined.md` into the latest run directory | | `cursor-learn:sitemap` | Regenerate `cursor-learn-discovered.csv` from cursor.com sitemaps | ```bash pnpm exec nx run generic-doc-scraper:scrape:cursor-learn pnpm exec nx run generic-doc-scraper:concat:cursor-learn ``` Runbook: [docs/cursor-learn-scrape.md](../../docs/cursor-learn-scrape.md). ## Bright Data docs Bright Data exposes a full index at [docs.brightdata.com/llms.txt](https://docs.brightdata.com/llms.txt). To scrape all docs: 1. Generate CSV from the index: `node tools/brightdata-llms-to-csv.mjs` 2. Run: `pnpm nx run generic-doc-scraper:scrape -- --input data/manifests/brightdata-full.csv --input-format csv --output-root docs --source-id brightdata --mode http --concurrency 10 --allow-partial` See [docs/brightdata-integration.md](../../docs/brightdata-integration.md) for details and optional adapter plan. ## OpenAI Codex and Claude Code docs Indexes: [developers.openai.com/codex/llms.txt](https://developers.openai.com/codex/llms.txt), [code.claude.com/docs/llms.txt](https://code.claude.com/docs/llms.txt). | Target | Description | |--------|-------------| | `openai-codex:llms` | Regenerate [openai-codex.csv](../../data/manifests/openai-codex.csv) | | `claude-code-docs:llms` | Regenerate [claude-code-docs.csv](../../data/manifests/claude-code-docs.csv) | | `scrape:openai-codex` | Scrape OpenAI Codex docs | | `scrape:claude-code-docs` | Scrape Claude Code docs | | `concat:openai-codex` | Write `openai-codex-combined.md` for the latest run | | `concat:claude-code-docs` | Write `claude-code-docs-combined.md` for the latest run | Runbook: [docs/openai-claude-docs-scrape.md](../../docs/openai-claude-docs-scrape.md). ## Output layout - `docs/<sourceId>/runs/<YYYY-MM-DDTHH-mm-ssZ>/manifest.json` - `docs/<sourceId>/runs/<YYYY-MM-DDTHH-mm-ssZ>/diff.json` - `docs/<sourceId>/runs/<run>/pages/<pageType>/<category>/<group>/<slug>.md` - `docs/<sourceId>/runs/<run>/raw/...` - `docs/<sourceId>/runs/<run>/indexes/protocol/*.md` - `docs/<sourceId>/runs/<run>/indexes/taxonomy/...` - `docs/<sourceId>/runs/<run>/indexes/source-master.md` - `docs/<sourceId>/latest.json`
