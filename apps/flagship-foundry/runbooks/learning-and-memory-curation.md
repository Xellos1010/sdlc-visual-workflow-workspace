# Learning and Memory Curation Runbook

## Purpose
Convert completed work and resolved incidents into reusable intelligence.

## Inputs
- work orders
- evidence bundles
- diffs
- postmortem notes

## Steps
1. Confirm the issue was actually resolved.
2. Capture environment, symptoms, and validated root cause.
3. Summarize the solution and design paradigm.
4. Extract reusable patterns and prevention rules.
5. Tag by domain, platform, language, and risk.
6. Mark whether the record is training-corpus eligible.

## Outputs
- fix-memory record
- training-corpus candidate
- guardrail updates
