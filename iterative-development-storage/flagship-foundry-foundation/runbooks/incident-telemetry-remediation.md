# Incident and Telemetry Remediation Runbook

## Purpose
Translate runtime evidence into a bounded remediation plan.

## Inputs
- incident or telemetry event
- graph relationships
- alert metadata
- affected systems/components

## Steps
1. Preserve the observed evidence and source links.
2. Classify severity and containment urgency.
3. Map telemetry to graph entities.
4. Create a derived change request.
5. Generate diagnosis and remediation work orders.
6. Require independent verification before closure.
7. Capture fix-memory and guardrail improvement candidates.

## Outputs
- derived change request
- remediation plan
- evidence bundle
- learning record
