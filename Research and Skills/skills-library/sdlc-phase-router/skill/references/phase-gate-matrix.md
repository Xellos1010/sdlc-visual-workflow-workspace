# Phase gate matrix

| Lifecycle stage | Entry signal | Required gate before exit |
|---|---|---|
| intake | vague request, new idea, missing repo/project | intent packet and source list exist |
| discover | repo or project must be inspected | repository/context inventory exists |
| define | requirements, acceptance criteria, unknowns | requirements and unknowns classified |
| design | ADR, schema, interface, architecture | decision and contract artifacts exist |
| plan | chunk, scope, work order, locks | bounded work order, tests, lock plan |
| implement | code/docs edit inside approved scope | changes are inserted and self-reviewed |
| verify | test, review, prove, validate | evidence bundle supports claims |
| integrate | PR, branch, conflicts, consolidation | one canonical PR and merge readiness |
| release | release notes, handoff, rollback | release and rollback materials ready |
| operate | scheduled audit, cleanup, monitoring | digest or maintenance artifact written |
| diagnose | bug, incident, failure, root cause | cause, fix path, and evidence captured |
| improve | retrospective, learning, guardrail | fix-memory or process update proposed |
