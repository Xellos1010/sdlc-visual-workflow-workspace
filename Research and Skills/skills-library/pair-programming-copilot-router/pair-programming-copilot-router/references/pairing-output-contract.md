# Pairing Output Contract

Use this reference when preparing a pairing plan.

## Required sections

1. Mode selected
2. Operator role and agent role
3. Allowed actions
4. Blocked actions
5. Manual checkpoints
6. Questions
7. Artifacts to inspect
8. Next skill handoff

## Default checkpoint cadence

Use a checkpoint after each irreversible, risky, or multi-file change. For low-risk explanation-only sessions, summarize the next checkpoint at the end.
