# Roadmap taxonomy

## Feature status
- candidate: idea exists but requires discovery
- defined: requirements and acceptance criteria exist
- designed: contracts, ADRs, or architecture are available
- planned: bounded work orders exist
- in_progress: implementation is active
- verify_ready: implementation requires validation
- blocked: external approval, dependency, or context missing
- done: verified, integrated, and continuity updated

## Feature types
- product capability
- platform capability
- refactor or architecture improvement
- bug fix or reliability improvement
- security or compliance improvement
- developer experience improvement
- operational maintenance

## Prioritization signals
- user impact
- revenue or mission impact
- risk reduction
- dependency unlock
- deadline or external commitment
- implementation complexity
- evidence quality
