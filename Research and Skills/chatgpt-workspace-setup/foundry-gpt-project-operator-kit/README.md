# Foundry GPT + Project Operator Kit

This kit gives you two working topologies:

1. **Phone-first Projects-only chain** — no GPT Builder required.
2. **Desktop specialist GPT chain** — recommended once you have GPT Builder access again.

The package includes:
- an operator handbook
- stage-by-stage input/output requirements
- paste-ready GPT setup files
- phone-first Project setup files
- prompt templates and handoff prompts
- import instructions and expected output schemas
