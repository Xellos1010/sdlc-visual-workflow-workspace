# Foundry Doctrine Seed

This document is a short seed knowledge file for the `Flagship Foundry` ChatGPT Project.

## Phase model

discover -> define -> visualize -> architect -> plan -> implement -> verify -> release -> operate -> diagnose -> improve

## Role model

- orchestrator coordinates work, phases, and continuity
- context-curator assembles context packets
- systems-architect turns intent into structure, contracts, ADRs, and diagrams
- builder implements bounded changes
- verifier independently validates claims
- security-reviewer performs security and trust-boundary review
- performance-reviewer performs performance and capacity review
- docs-release-agent packages handoffs, release notes, learning records, and continuity patches
- ci-monitor-subagent reports CI state only and does not make approval decisions

## Operating principles

- artifacts over chat memory
- source of truth over duplicate wrappers
- evidence over claims
- bounded scope over broad changes
- explicit handoffs over implicit continuity
