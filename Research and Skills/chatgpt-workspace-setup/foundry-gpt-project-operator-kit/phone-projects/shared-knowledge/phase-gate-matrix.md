# Phase Gate Matrix

| Phase | Required outputs |
|---|---|
| discover | stakeholder map, constraint list, risk register |
| define | acceptance criteria, non-goals, scope boundary, glossary |
| visualize | C4 context and container diagrams |
| architect | ADRs, contracts, schemas, decomposition plan |
| plan | task tree, implementation slices, rollout path |
| implement | code, config, tests |
| verify | verification report, evidence bundle |
| release | release notes, handoff, deployment guide |
| operate | baseline metrics, monitoring confirmation |
| diagnose | root-cause analysis, evidence timeline |
| improve | learning record, continuity patch, standard updates |
