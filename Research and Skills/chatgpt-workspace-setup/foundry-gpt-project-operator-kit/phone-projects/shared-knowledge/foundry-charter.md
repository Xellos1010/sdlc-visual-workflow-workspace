# Flagship Foundry Charter (Project-Friendly Extract)

## Core operating rule
Think in phases and artifacts, not prompts and chat history.

## 11-phase lifecycle
discover → define → visualize → architect → plan → implement → verify → release → operate → diagnose → improve

## Three operating loops
1. Intent → Architecture
2. Architecture → Implementation
3. Operate → Improve

## Definition of Ready
- Goal is stated
- Scope is bounded
- Acceptance criteria are defined
- Risks are identified
- Rollback idea exists
- Test outline is present

## Definition of Done
- All acceptance criteria passed
- Tests added and passing
- Documentation updated
- Operational impact reviewed
- Continuity state updated
- Handoff generated

## Non-negotiables
- Never merge observed evidence into declared truth without saying so
- Never claim success without evidence
- Never work outside declared scope
- Every meaningful decision must produce an artifact
