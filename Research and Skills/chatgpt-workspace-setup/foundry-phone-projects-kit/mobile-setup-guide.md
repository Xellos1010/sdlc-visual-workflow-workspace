# Mobile Setup Guide

## What to do on your phone
1. Create the Projects in the order listed in `project-chain-map.md`.
2. For each Project:
   - use the exact Project name in its folder
   - paste `project-instructions.md` into Project instructions
   - upload the files listed in `knowledge-upload-list.md`
   - start a new chat using the first prompt in `starter-prompts.md`
3. Save important ChatGPT outputs back into the Project as project sources.
4. Before moving to the next Project, carry forward:
   - the main artifact bundle
   - `artifact-manifest.json`
   - `foundry-import-manifest.json`
   - `next-workspace.txt`

## File creation rule
Tell the Project to create downloadable files. If it creates multiple files, tell it to zip them into one bundle and include an artifact manifest.

## Manual only
This kit is designed for manual setup in ChatGPT Projects. It does not assume any automated bulk import mechanism.
