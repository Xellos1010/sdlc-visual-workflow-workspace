# Flagship Foundry — Phone-First ChatGPT Projects Kit

This kit is for a first deployment round using only ChatGPT Projects and uploaded files.

## Goal
Create a chain of Projects that can:
1. Turn a raw request into an approved intent packet
2. Produce architecture artifacts before implementation
3. Emit fully-specified work orders for low-cost parallel execution
4. Validate evidence and generate docs and learning artifacts
5. Package everything for import back into Foundry

Read `mobile-setup-guide.md` first.
