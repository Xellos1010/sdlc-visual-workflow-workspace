# Foundry Import Protocol

## Pre-implementation imports
Import approved design artifacts before code execution:
- intent packet
- impacted systems list
- diagrams
- ADRs
- contracts and schemas
- decomposition plan
- work-order tree

## Post-verification imports
Import only after verification passes:
- verification report
- evidence bundle
- release notes
- handoff
- learning record
- continuity patch
- artifact manifest

## Knowledge-base rule
Read KB before planning. Write KB only after verification or diagnosis produces verified learning.
