# GPT Specific Project Bundle

## Purpose
A custom GPT build kit for a reusable project-scoping assistant that can turn new client briefs into pitch proposals, UI/UX artifact plans, flow diagrams, integration maps, phased release schedules, and pricing packets.

## Best-fit use case
Use this when you want a **dedicated GPT** instead of a one-off Project.

## Important platform note
- GPTs can be used on mobile after they are created.
- Building or editing a GPT happens on the **web** experience.
- A GPT can include instructions, knowledge files, and enabled capabilities.
- A GPT can use either apps or actions, but not both at the same time.

## Included
- system prompt
- builder instructions
- conversation starters
- knowledge files optimized for GPT uploads
- knowledge manifest
- expected outputs
- sample Homo Plasticus example outputs
