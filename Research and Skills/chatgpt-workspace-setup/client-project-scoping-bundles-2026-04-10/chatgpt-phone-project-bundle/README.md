# ChatGPT Phone Project Bundle

## Purpose
A mobile-friendly ChatGPT Project kit for recurring client scoping, pitch proposal generation, UI/UX artifact planning, pricing, phasing, and invoice creation.

## Best-fit use case
Use this when you want to stand up a manual ChatGPT Project on phone or tablet and feed it a new client brief, current website files, screenshots, repo summaries, and delivery requirements.

## Important platform note
- ChatGPT Projects work well for this because they keep chats, files, and custom instructions together.
- Projects sync across phone and web.
- This bundle is optimized for **manual setup on phone first**.
- If you later want a reusable dedicated assistant, use the sibling **GPT Specific Project Bundle**.

## Included
- project instructions
- starter prompts
- knowledge upload list
- initiative-agnostic knowledge files
- expected output contract
- JSON schema for proposal outputs
- reusable templates
- example Homo Plasticus scope packet reference

## Recommended setup
1. Create a new ChatGPT Project named `Client Scope & Pitch Factory — Mobile`.
2. Paste `project-instructions.md` into the Project instructions.
3. Upload the files listed in `knowledge-upload-list.md`.
4. Start with the first starter prompt.
5. Ask the Project to generate downloadable files and zip them when multiple artifacts are produced.

See `../sources.md` for source references.
