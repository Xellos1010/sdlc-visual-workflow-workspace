# UI/UX Artifact Playbook

## Always generate
- sitemap / information architecture
- primary user flow
- admin / operator flow if any dashboard exists
- responsive notes for mobile, tablet, desktop
- screen inventory
- component inventory
- content model summary

## Generate when scope requires
- wireframes
- dashboard IA
- states matrix (empty/loading/error/success)
- motion notes
- commerce flow map
- approval workflow diagram
- analytics event map

## Diagram standards
Use Mermaid when the user wants quick artifact generation.

### Project flow chart
Show the delivery sequence by phase.

### User flow diagram
Show how the end user or admin moves through the experience.

### Integration map
Show external systems and trust boundaries.
