# Starter Prompts

## 1) Full project scope and pitch
Use the uploaded brief, current site files, screenshots, and repo summaries to generate a full client scoping packet and downloadable zip bundle. Include: current-state audit, active resource inventory, recommended stack, UI/UX artifact plan, flow charts, user flows, systems integration analysis, phased release schedule, standard market pricing, recommended offer pricing, and an itemized invoice by phase.

## 2) Fast estimate only
Using the uploaded brief and files, create a fast scoping estimate with assumptions, phase breakdown, market range, recommended offer, and top five risks.

## 3) UI/UX artifact pass
Generate only the UI/UX artifact pack for this initiative: sitemap, screen list, component inventory, user flows, content model, and responsive considerations.

## 4) Proposal refinement
Using the previously generated scoping packet, rewrite it as a client-facing pitch proposal with tighter language, clearer deliverables, and a cleaner pricing presentation.

## 5) Change request re-scope
Given this new requirement or change request, update the original scope, highlight delta impact, and produce a revised phase plan and revised invoice.
