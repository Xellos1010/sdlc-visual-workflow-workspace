# Expected Output Contract

The Project must be able to generate a scoping packet that can be turned into a client proposal without further restructuring.

## Minimum file set
- executive-summary.md
- current-state-audit.md
- active-resource-inventory.md
- recommended-stack.md
- uiux-artifact-plan.md
- project-flow.mmd
- user-flow-primary.mmd
- systems-integration-analysis.md
- phased-release-schedule.md
- pricing-matrix.csv
- invoice-by-phase.csv
- assumptions-and-risks.md
- artifact-manifest.json

## Acceptance criteria
- initiative-specific facts grounded in uploaded materials
- clearly labeled assumptions
- phase boundaries that separate launch from future expansions
- pricing shown as standard market vs recommended offer
- explicit exclusions
- mobile-first posture if no contrary requirement exists
- reusable method that can be applied to future clients
