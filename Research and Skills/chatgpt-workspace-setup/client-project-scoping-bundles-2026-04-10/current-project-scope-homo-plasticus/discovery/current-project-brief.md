# Current Project Brief

## Initiative
Homo Plasticus website transformation and reusable-client-stack definition.

## Immediate objective
Launch a stronger book-promotion website that is mobile-first, conversion-aware, SEO-ready, and able to sell the first digital book product.

## Required near-term capabilities
- mobile-first responsive website with desktop support
- book-promotion homepage and shop flow
- Stripe commerce for digital product delivery
- Apple Pay / Google Pay support through Stripe on web
- Google Tag Manager / Google Analytics setup
- Mailchimp integration and campaign posture
- robots.txt, sitemap.xml, and llms.txt discoverability layer
- reusable deployment and component pattern for future client sites

## Requested next-phase capabilities
- CMS dashboard for page, nav, footer, menu, and transition settings
- blog with AI-assisted drafting and human approval pipeline
- external affiliate links and later in-house product catalog
- affiliate management for future product catalog
- external AI chat management path or manual dashboard editing

## Requested timeline from operator
- 24-hour style sprint with 3 iterations for the website visual direction
- 3–5 day base launch for responsive site, SEO basics, analytics, and first digital storefront
- later phases for dashboard, blog, catalog, and advanced integrations
