# Phased Release Schedule

## Phase 0 — Style Sprint / Direction Lock
**Target:** 24 hours

### Deliverables
- 3 visual direction iterations for homepage + shop style
- responsive direction choice
- typography and design-token direction
- approval of CTA hierarchy and book-promotion message

## Phase 1 — Base Launch
**Target:** 3–5 days after direction lock

### Deliverables
- mobile-first responsive website build
- desktop validation pass
- homepage + impact + solutions + resources + shop
- Stripe digital book purchase flow
- GTM / GA4 integration
- Mailchimp capture setup
- robots.txt + sitemap.xml + llms.txt
- performance / SEO baseline

## Phase 2 — CMS + Blog + Content Ops
**Target:** 1–2 weeks depending on dashboard depth

### Deliverables
- admin dashboard / CMS foundation
- editable pages / nav / footer / menu / SEO surfaces
- blog module
- AI draft + human approval content flow foundation
- scheduling / publish controls

## Phase 3 — Commerce Expansion + Integrations
**Target:** after Phase 2 stabilizes

### Deliverables
- affiliate recommendation support
- in-house product catalog foundation
- affiliate management support
- advanced integrations and automation
- optional support / telephony / transactional workflow add-ons
