# Project Pitch Proposal — Homo Plasticus

## Executive Summary
Homo Plasticus should be repositioned as a mobile-first authority website that converts attention into book sales first, then grows into a managed content and commerce platform. The fastest path is a phased build: lock the style direction in 24 hours, launch the responsive book-focused website in 3–5 days, then add the CMS/blog/content-ops layer, and only after that expand into affiliate and catalog capabilities.

## What exists now
- a live public site with a five-page, book-led authority structure covering Home, Impact, Solutions, Resources, and Shop
- an uploaded local five-page HTML snapshot that serves as the clearest technical baseline for scoping the transition
- a reusable repo baseline with analytics, SEO, structured-data, dashboard, affiliate, and AWS-oriented implementation patterns

## What is missing now
- proven responsive behavior on the current shop experience
- wired analytics and marketing integrations
- live commerce flow for the digital book
- CMS/admin editing surface
- blog and content workflow engine
- affiliate and catalog systems
- production SEO / AI-discovery files and governance

## Recommended solution
Build the next version on a reusable composable stack that can be cloned for future clients. Treat the current local HTML and public site structure as the content and UX seed, not the final technical implementation. Launch Phase 1 as a clean, fast, mobile-first authority site with a working digital book checkout, then add the operator layer in Phase 2.

## Why this proposal is efficient
It reuses your existing patterns and avoids overbuilding the launch. The website earns the right to become a larger platform only after the book, content, analytics, and editing loop are stable.
