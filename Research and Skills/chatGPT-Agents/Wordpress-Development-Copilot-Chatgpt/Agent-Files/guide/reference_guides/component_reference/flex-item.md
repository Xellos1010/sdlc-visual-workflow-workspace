# FlexItem – Block Editor Handbook | Developer.WordPress.org

A layout component to contain items of a fixed width within `Flex`.

## [Usage](#usage)

See [`flex/README.md#usage`](https://developer.wordpress.org/block-editor/reference-guide/components/flex/flex/#usage) for how to use `FlexItem`.

## [Props](#props)

### [display: CSSProperties\[‘display’\]](#display-csspropertiesdisplay)

The CSS display property of `FlexItem`.

-   Required: No

### [isBlock: boolean](#isblock-boolean)

Determines if `FlexItem` should render as an adaptive full-width block.

-   Required: No
-   Default: `false`
